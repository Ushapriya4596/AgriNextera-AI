# 🌱 AgriNextera AI
### Smart Precision Irrigation & Crop Water Intelligence System

**Where Agriculture Meets Intelligence.**

AgriNextera AI is an AI-powered agricultural prototype that analyzes soil and environmental conditions using machine learning to generate irrigation-related predictions through an interactive dashboard.

## ✨ Key Features

- Field-condition based ML predictions.
- Interactive Field Predictor dashboard.
- Prediction probability visualization.
- Model Insights and feature importance.
- Model evaluation and performance metrics.
- Project information and technology overview.

## 🧠 Machine Learning

- Algorithm: Random Forest Classifier
- Dataset: 150 records
- Input features: 6
- Holdout accuracy: 96.67%
- 5-fold cross-validation accuracy: 94%

*Evaluation is based on a small dataset and does not establish real-world agricultural performance.*
